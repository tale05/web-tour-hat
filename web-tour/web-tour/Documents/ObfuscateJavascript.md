# Dùng thư viện obfuscate của node js đế mã hóa javascript

## # Cài đặt package.json

+ Location cần cài đặt package.json: cùng cấp với file web-tour.sln

	```npm init -y```

## # Cài đặt thư viện obfuscator
```npm install --save-dev javascript-obfuscator```

## # Tạo file obfuscate.js

## # Chạy file obfuscate.js

+ Location để chạy file: wwwroot/js

+ ```cd D:\WebsiteTour\hosting\web-tour\web-tour\wwwroot\js```

+ Để có thể chạy ở vị trí: "wwwroot/js" -> Không bị lỗi

+ Run: ```node obfuscate.js```
