## 📖 Project Overview

**DuLichHat.com** is a tourism-focused website developed to provide users with an easy way to explore and book travel experiences.  
The project was implemented using **C#** and the **ASP.NET Core MVC framework**, with a strong focus on responsive design, secure authentication, and optimized performance.

---

## 🖥️ Technology Stack

### Frontend

- **HTML, CSS, JavaScript** – Core web technologies for UI/UX development
- **jQuery** – Simplified DOM manipulation
- **TinyMCE** – Rich text editor for content management
- **elFinder** – Efficient image browsing and file management in the backend
- **Bootstrap** – Responsive and mobile-first UI framework
- **Google reCAPTCHA** – Protection against spam and automated bots

### Backend

- **C# with ASP.NET Core MVC** – Server-side logic and business processing
- **Entity Framework Core** – ORM for database interaction using LINQ and entity models
- **AspNetCoreRateLimit** – Request throttling to prevent abuse
- **BCrypt.Net-Next** – Secure password hashing for authentication
- **Hashids.net** – Obfuscation of numerical IDs into short, non-sequential strings

### Database

- **SQL Server** – Designed and managed using **SQL Server Management Studio (SSMS)**
